# Madupu Manish Reddy | Developer Portfolio

A personal portfolio focused on AI/ML engineering and full-stack software development, featuring project case studies, technical skills, education, and community involvement.

## Technologies

- React and TypeScript
- Vite
- Tailwind CSS
- Framer Motion
- React Router
- Lucide React

## Run Locally

```bash
npm install
npm run dev
```

Create a production build with:

```bash
npm run build
```

Preview the build locally with `npm run preview`.

## Project Structure

- `src/components/` — page sections and visual components
- `src/data/` — profile, project, skill, community, and education content
- `src/pages/` — home, project detail, and not-found routes
- `public/` — static icons and favicon
